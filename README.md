## Навигация:

В папке data - наш датасет (добавлена в .gitignore)
В ней - папка gymhero, по которой проходит парсер и достает весь код + eval_questions.json + sample_queries.txt (**сверьтесь чтобы у всех была такая структура**)

### Парсер/чанкер (Дима)

RAG/ast-chunker.py - python-скрипт, который проходит по датасету и чанкует функции и методы класса (парсер)

RAG/chunks_ast.jsonl - json-файл, содержащий чанки фукнций и методов класса (этот файл берет Даша и преобразует в эмбеддинги, то же что мы делали в первом этапе)

**Что фиксануть**: не создавать отдельный чанк для целого класса а только для методов

### Генерация эмбеддингов (Злата)

Берем RAG/chunks_ast.jsonl и просто делаем то же самое, что в первом этапе чемпа
Пока что базы данных у нас нет, поэтому просто сохраняй наверное в список


Использована модель `BAAI/bge-m3`

Результат:
- 155 чанков
- Размерность эмбеддинга: 1024
- Формат: JSON + pickle

Запуск: `python3 RAG/generate_embeddings.py`
